# SignLearn

SignLearn is an application designed to help users learn and recognize sign language gestures using machine learning. This project provides a simple interface for uploading gesture images, receiving predictions, and browsing a curated set of sign language data.

## 🛠️ Setup & Installation
~~~
git clone https://github.com/TheUnmeshRaj/SignLearn.git
cd SignLearn
pip install -r requirements.txt
~~~
Place any required pre-trained model files as specified in project instructions.

## ⚡ Usage

streamlit run app.py

- Open your browser to the local Streamlit link provided in the terminal.
- Upload images or use demo gestures for recognition.
- Browse the dataset or test the prediction capabilities.

## 📁 Repository Structure

| File/Folder      | Description                                   |
|------------------|-----------------------------------------------|
| app.py           | Streamlit web application                     |
| requirements.txt | Python dependencies                           |
| model/           | Pretrained models (if provided/required)      |
| dataset/         | Sign language gesture image data              |
| utils.py         | Utility functions for preprocessing, etc.     |
